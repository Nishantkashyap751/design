DEEP SPACE HUD ASSET PACK

These layers were recreated from the supplied flattened mockup. PNG files are
3x exports for direct import. SVG files are editable vector masters.

Layer order
1. Starfield background, then orbital trails. Both share a 600 x 1250 canvas.
2. Date and clock as live text. Use title-rule on either side of the date.
3. Countdown panel, orbital diagram, four countdown tiles and separators.
4. Live countdown and progress text. Overlay progress-fill on progress-track.
   Set fill width to the current progress percentage. The reference shows 60%.
5. Repeat mission-row six times. Add the appropriate icon, alternating cyan
   and violet accents, a live label, and the reusable chevron.
6. Add cellular, Wi-Fi, and battery icons if drawing a custom status bar.

The reference PNG shows alignment and appearance. Asset dimensions are in the
SVG viewBoxes. The phone chassis and cockpit appear in the reference only.
